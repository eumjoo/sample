# Nephron Lab · 네프론 탐구 실험실

혈구, 단백질, 요소, 물, 포도당, 아미노산의 이동을 관찰하는 한국어 3D 학습 시뮬레이션입니다.

## 바로 열기 (설치·서버 불필요)

저장소 최상위의 `index.html`을 다운로드한 뒤 브라우저에서 엽니다. SVG 그림, CSS, JavaScript, 3D 라이브러리가 이 파일 하나에 포함되어 있어 인터넷이나 개발 서버가 필요하지 않습니다. GitHub의 코드 보기 화면은 HTML을 실행하지 않으므로 파일을 다운로드해서 열어야 합니다.

제목, 화면 구성, 네프론 그림은 HTML에 직접 포함되어 JavaScript가 차단되어도 표시됩니다. 애니메이션과 상황 선택에는 JavaScript가 필요하며, 3D만 WebGL이 필요합니다. 초기화 실패 시 별도의 그림과 이동 표를 표시합니다.

## 개발

Node.js 20.19+ 또는 22.12+를 사용합니다. 현재 환경은 Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev
```

개발용 HTML은 `src/index.html`입니다. 최상위 `index.html`은 소스를 묶은 생성 파일이므로 직접 수정하지 마세요. 소스 수정 후 `npm run build`로 다시 생성하고 함께 커밋합니다.

## 빌드와 배포

```sh
npm run build
```

일반 웹 배포는 `dist/` 전체를 올립니다. 상대 경로를 사용하므로 `/sample/` 같은 하위 경로도 지원합니다. 파일 하나만 공유하려면 최상위 `index.html` 또는 `dist/standalone.html`을 사용합니다.

GitHub Pages를 `main` 브랜치의 `/(root)`에서 게시하는 경우 커밋된 최상위 `index.html`을 그대로 사용합니다. `.nojekyll`을 포함하여 정적 파일을 그대로 게시합니다. 게시 주소는 https://eumjoo.github.io/sample/ 입니다.

## 사용법

- 정상 상태, 수분 부족, 물 마신 후 중 상황을 선택합니다.
- 물질 버튼으로 원하는 입자만 표시합니다. 혈구와 대부분의 단백질은 혈액에 남습니다.
- 여과·재흡수·분비 카드를 눌러 관 사이의 해당 이동을 강조합니다.
- 기본 화면은 WebGL 없이 동작하는 네프론 그림과 입자 애니메이션입니다.
- 3D 모델 버튼을 누르면 입체 모형을 불러옵니다. 드래그로 회전하고 스크롤로 확대합니다. 네프론 그림, 자동 회전, 일시정지, 속도 변경, 초기화를 지원합니다.
- 수분 부족은 집합관의 물 재흡수 입자가 늘고 소변으로 나가는 물 입자가 줄어듭니다. 물 마신 후에는 반대로 바뀝니다.

## 검증

```sh
npm test
npm run build
npm run test:e2e
```

브라우저 테스트는 기본적으로 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 `playwright.config.js`의 실행 경로를 조정하세요. 먼저 빌드한 후 테스트합니다. WebGL 차단, 컨텍스트 손실, 모바일, 외부 요청 없는 오프라인 단일 HTML 실행, JavaScript 차단 시 정적 그림, 하위 경로의 프로덕션 빌드 로딩을 검증합니다.

## 학습 모델의 범위

입자 수, 속도, 관의 비율은 실제 농도나 이동 속도를 재현하지 않습니다. 수치는 양쪽 신장의 합산 학습용 추정치입니다. 수분 상태와 ADH의 관계를 비교하도록 단순화했으며 진단에 사용할 수 없습니다. 정상적인 신장 기능과 정상 혈당을 가정하며 포도당·아미노산은 근위세뇨관에서 재흡수됩니다. 분비에서는 선택한 여섯 물질 중 요소의 재순환(집합관 → 간질 → 헨레고리)을 보여줍니다. 실제 신장의 H⁺·K⁺·약물 분비는 별도 설명으로만 안내합니다.

Vite와 Three.js로 구현했으며 외부 API, 비밀 키, 데이터베이스가 필요하지 않습니다.
